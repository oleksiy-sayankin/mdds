# MDDS Python Worker Runtime Common

Python Worker Runtime Common for the MDDS job orchestration platform.

This package provides reusable Python runtime infrastructure for loading
an MDDS Worker Manifest, building WorkerExecutionContext, invoking a
WorkerHandler, validating locally produced outputs, and mapping execution
results to process exit codes.
